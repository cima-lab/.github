# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately to **cimalab@gmail.com**
rather than opening a public issue. Include what you found, how to reproduce
it, and its potential impact. We'll acknowledge your report and follow up as
we investigate.

## Reporting patient or human-subject data exposure

If you find patient data, PII, or other human-subject data in any CIMA Lab
repository, treat it as a priority security issue: email cimalab@gmail.com
immediately. Do not open a public issue, and do not clone or fork the
repository beyond what's necessary to report it.

## Scope

This policy covers repositories under the [cima-lab](https://github.com/cima-lab)
GitHub organisation.
